DESCRICAO GERAL

O A11yAudit combina uma interface responsiva em HTML, CSS e JavaScript com uma API Flask em Python. O usuario informa uma URL publica, o backend baixa o HTML da pagina e o analisador verifica elementos comuns relacionados a acessibilidade. Os resultados sao classificados por severidade e convertidos em uma pontuacao.

MOTOR DE ANALISE

Penalidades:
- Erro: 8 pontos.
- Aviso: 4 pontos.
- Informativo: 1 ponto.
- Pontuacao minima: 0.

Ocorrencias analisadas:
- Idioma ausente no elemento html.
- Imagens sem atributo alt.
- Botoes sem texto, aria-label ou title.
- Links sem texto ou nome acessivel.
- Campos sem label ou atributos ARIA associados.
- Hierarquia incorreta de titulos.
- Quantidade incomum de h1.
- Meta viewport ausente.
- Titulo da pagina ausente.
